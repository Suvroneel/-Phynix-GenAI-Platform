# Phynix Mental Health Chatbot

Achieved 90% emotion classification accuracy by fine-tuning a BERT-based NLP model to classify user inputs in real time and generate emotion-aware chatbot responses.

Built dashboards to track user emotions and confidence scores over time, helping surface patterns in engagement and emotional responses.

Integrated model inference with backend services to support authenticated users, persistent storage, and low-latency interactions in a production-style setup.
